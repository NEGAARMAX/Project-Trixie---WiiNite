# Source layout

- `Desktop/Light/` and `Desktop/Dark/`: Desktop theme source as provided in the original source ZIP.
- `Fullscreen/Original/` and `Fullscreen/Dark/`: contents of the original installable Fullscreen BYOA packages, extracted without changes to file contents.
- `screenshots/`: README illustrations.

The four original `.pthm` packages are distributed separately in the GitHub Release. Do not repackage these source folders as `.pthm` without validating the resulting package in Playnite.
